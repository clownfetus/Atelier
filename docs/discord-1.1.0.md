**Atelier 1.1 is out!**

The latest Model Studio and library updates are together in one release.

• **Add your own assets:** create named textures, materials and meshes at a custom game path, then edit and build them through the Mod tray.
• **Export to Blender:** take the visible body and held weapons into one portable .blend, with connected materials, packed textures and deformation bones.
• **More model controls:** separate body/weapon replacements, model and texture bundles, and section visibility saved into the exported mod.
• **A clearer library:** hero and costume nameplates, sharper banners, larger portraits, saved card sizes and a remembered Heroes startup view. Double-click a portrait to open its folder.
• **See what's new:** an offline changelog after updates, including releases you skipped.

Windows installer + Linux AppImage, with matching source, checksums and verification results.

Download: https://github.com/clownfetus/Atelier/releases/tag/1.1.0

Windows: close Atelier and run the installer in your existing location. Linux: download the new AppImage and mark it executable.

Blender export needs Blender configured in Settings. Game physics and animation controls aren't recreated; custom model appearance still needs checking in game.
