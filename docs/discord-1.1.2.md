**Atelier 1.1.2**

More tools for editing, and a workspace that feels more connected.

• Fluid ink now follows loading, saving, exports and configuration discovery. It travels through panel borders, uses the current hero or costume colours, and reacts when work finishes. Try it in Settings → Try Krackle.
• A matching Windows installer with Paper and Ink artwork and clearer setup screens.
• Assembly View connects model surfaces to their materials, textures, UV tools and Blender workflows.
• UV X-Ray shows a picked surface's UV0 wireframe over its texture and exports a transparent wireframe PNG.
• VFX Motionboard adds synchronized Niagara tracks, scrubbing, comparisons and per-point restores, with 2D particle proxies for arranging a preview.
• Review and save material changes across up to 1,000 assets at once, including colours, scalars, opacity and parent changes.
• Corrected hero artwork, cached costume previews and better protection for edits made while a save is running.

Windows installer, portable ZIP and Linux AppImage, with matching source, screenshots and checksums.

Download: https://github.com/clownfetus/Atelier/releases/tag/1.1.2

Windows: close Atelier and install to the existing location. Linux: download the new AppImage and mark it executable.

Motionboard proxies don't reproduce Unreal rendering. UV X-Ray shows decoded UV0. In-game appearance still needs checking; Calm, Off and reduced-motion options remain available.
