# Atelier 0.4 is out

This update gives the 3D viewer a cleaner workspace and adds model replacements
to the edit list. The screen flashing when you load textures is fixed too.

- **A redesigned Model Studio.** Editing controls appear when you need them,
  edited textures load automatically, compatible idle animations loop by default,
  and loading is clearer. Rim lighting no longer gets in the way of the model.
- **Model replacements.** Import BLEND, FBX, GLB, PSK/PSKX or cooked Unreal meshes
  and build them into the same mod as your other edits. Keeping the original
  skeleton, compatible weights and facial/corrective morph targets is on by
  default, with options to change this during import.
- **Smoother editing.** Texture imports keep the library in place. Revert to
  original keeps assets in your edit list, and newly available high-resolution
  textures are recovered automatically while preserving your painted edits.
- **A clearer library.** Stronger editing borders, roster arrows, transparent
  character artwork, artwork-coloured skin names and green build-success panels.

Windows and Linux builds are available. Restart Atelier to check for the Windows
update, or download the installer or AppImage from GitHub. The version shown in
the app is **0.4.0**.
