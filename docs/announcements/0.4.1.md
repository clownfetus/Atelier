# Atelier 0.4.1 is out

This update lets you use your own images in a material's texture slots, fixes
mesh editing in Blender, and gives Atelier's feedback a new look.

- **Your own textures (experimental).** The material editor now lists each
  material's texture slots. Give a 2D slot your own image and it ships as a new
  texture that only that material uses, so other skins and chromas sharing the
  game texture don't change. Your image is encoded like the texture it replaces,
  and each side must be a power of two (1024, 2048…). This hasn't been tested in
  game yet, so reports from your exports are very welcome.
- **Open in Blender works again.** Mesh editing could fail with "all the input
  array dimensions … must match exactly" in Blender 4.5–5.1. That's fixed.
- **Clearer Model Studio errors.** When a model can't load, Atelier now says why
  instead of "404: Not Found".
- **Fewer lost edits.** The Curve, VFX, Level and Text editors ask before closing
  with unsaved changes, and Reset and Revert to original ask before replacing
  saved edits.
- **Krackle feedback.** Progress, success, warning and error moments, empty
  states and the export and import dialogs use the new comic-style Krackle look.

On Windows, restart Atelier and choose **Update Now**. On Linux, download the new
AppImage. The version shown in the app is **0.4.1**.
