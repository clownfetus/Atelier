**Atelier 1.1.1**

A patch for model loading, previews and texture exports, with a few new options.

• Character and costume names now show across more asset folders, including legendary ultimate skins, search and asset pickers.
• Import HDR cubemaps from .hdr panoramas, six-face strips or HDR DDS files, and use them in material reflection slots.
• Open a model in Blender with its textures packed into the .blend, without adding them all to your project. The option is in Settings → Behavior; existing painted textures are kept.
• Faster repeated model preparation on Windows, with the selected body and weapons loaded first.
• Fixes for character materials, masks, weapon grips, alternate forms and the T_Visor texture export error.
• Cleaner library filters, compact captions, Mod tray spacing and updated Showcase and Krackle feedback.

Windows installer, portable ZIP and Linux AppImage, with source and checksums.

Download: https://github.com/clownfetus/Atelier/releases/tag/1.1.1

Windows: close Atelier and install to your existing location. Linux: download the new AppImage and mark it executable.

HDR export has native readback checks; in-game rendering still needs checking. Full animated shaders aren't reproduced in previews.
