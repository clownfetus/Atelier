**Atelier 1.0 is here!**

All the recent UI and workflow updates are together in one release.

• **Find things faster:** hero and costume browsing, search across the whole library, and Continue editing.
• **Replace materials:** use a material from another character or skin, keep editing its parameters, or restore game defaults.
• **Show off your work:** Inspect and Showcase views, posters, turntables, and shareable Mod cards after a build.
• **Recover deleted edits:** project trash and Undo.
• **A fresh look:** the new Krackle A logo, updated themes and surfaces, clearer progress, and Full / Calm / Off motion. Optional sounds are off by default.
• **A smoother workflow:** guided setup, the Mod tray, Build mod review, image drag and drop, and faster startup.

Windows installer + Linux AppImage, with matching source and checksums.
Download: https://github.com/clownfetus/Atelier/releases/tag/1.0.0

Windows: close Atelier and run the new installer in your existing location. Linux: download the new AppImage and mark it executable.
